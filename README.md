# 啤酒风味图谱 · Beer Flavor Atlas

把数学建模论文《基于多输出偏最小二乘、共表达网络与风格条件生成模型的啤酒风味解析与调控》
中的表格与结论，做成一个可交互的风味可视化站点。纯静态页面，无框架、无外部依赖、无网络请求。

**在线地址** <https://likangyu070710-source.github.io/beer-flavor-atlas/>
**仓库** <https://github.com/likangyu070710-source/beer-flavor-atlas>

## 六个页面

| 页面 | 文件 | 做了什么 |
| --- | --- | --- |
| 首页 | `index.html` | 主视觉、四个数据规模、五个入口、四种风格卡片 |
| 风格查询 | `styles.html` | 22 个风格卡片（搜索 + 分类筛选），点开为风格档案：12 轴感官雷达、12 个关键化合物及其含量区间、化学指纹正负各 5 位、论文 50 维 Top-3 证据表 |
| 化合物交互 | `lab.html` | 55 个化合物目录，点击增删；实时给出组合的感官轮廓、与目标风格的贴合度、逐化合物的感官属性与影响方向/强度；含入瓶动画与试饮表情 |
| 口味生成 | `note.html` | 按当前组合生成 100–200 字品鉴笔记（香气 / 口感 / 余味），高亮主导化合物，可换写法、复制 |
| 风格溯源 | `origin.html` | Tripel 的四段工艺时间线、风格轴图、原料—工艺—化合物—风味因果链、化学指纹、位移清单与稀疏化路径 |
| 风格迁移 | `transfer.html` | 任选源/目标风格，输出干预清单（新增/删减/上调/下调 + 用量区间）、五段迁移路径、差值对比与缺陷不恶化校验 |

导航是真实的 `<a href>`，不是 hash 路由：每一页有自己的地址、自己的标题、自己的 `h1`，
可以收藏、可以新标签打开、可以分享。当前页在导航里带 `aria-current="page"`。

页面之间的状态用 `sessionStorage` 延续——在风格库点「在化合物台打开」，到化合物页时组合已经在里面了；
关掉标签页即清空，不留长期痕迹。

## 运行

直接双击 `index.html` 也能看，但多页之间跳转建议用本地服务（避免 `file://` 对存储的限制）：

```bash
cd beer-flavor-atlas
python -m http.server 8000
# 打开 http://localhost:8000
```

## 数据文件结构

`data/flavor-data.js` 是一个 JSON 字面量，字段如下：

```js
window.BEER_DATA = {
  meta:      { title, subtitle, paper, team, updated, scale_note },
  axes:      [{ id, cn, en }],                 // 12 条感官轴
  groups:    [{ id, cn }],                     // 风格族（拉格/艾尔/小麦/酸啤…）
  families:  [{ id, cn, en, color }],           // 化合物来源（酵母/酒花/麦芽/酚类/野生菌群/理化）
  modules:   [{ id, label, size, hint, reps }], // 表 6 的六个共表达模块
  compounds: [{
    id, cn, en, family, module, unit, ref,     // ref = 基准浓度（相对指数的 100%）
    imp,                                       // 重要性权重，影响排序
    defect,                                    // 是否属于四个缺陷化合物
    sens: { bitter: 0.9, ... },                // 12 轴敏感度，-1..1
    aroma, palate, finish, note, src           // 气味描述、口感、余味、机制、论文出处
  }],
  styles: [{
    id, cn, en, group, alias, n, abv, desc, src,
    profile: { bitter: 4.0, ... },             // 12 轴 0–6 分画像
    values:  { [compoundId]: [lo, mid, hi] },  // 该风格下的含量区间（化合物自身单位）
    key:     [compoundId, ...],                // 关键化合物（按贡献度排序）
    fp:      { pos: [{id, d}], neg: [{id, d}], src, notes }  // 化学指纹
  }],
  evidence: [{ id, cn, group, tier, top: [{ en, cn, pi, rho, relaxed }] }], // 表 21
  paper:    { facts, network, axes, tripel, generation, markers }            // 原文数值
};
```

### 调整数据

- **改数值**：直接编辑 `data/flavor-data.js`。例如把某风格某化合物的区间从 `[3.4, 4.9, 6.8]` 改成别的，
  刷新即可；雷达、表格、迁移清单、品鉴笔记都会跟着变。
- **改画像**：修改 `styles[i].profile` 的 0–6 分值，风格卡片、详情雷达与迁移差值同步更新。
- **重跑生成**：`python tools/build_data.py`，脚本会把 `tools/build_data.py` 里的化合物表、
  风格画像、特征组合（`OVERRIDE`）重新算成 `data/flavor-data.js`。

## 数据口径

- 论文未逐格公布 226 项指标在 22 个风格上的实测浓度。站内的**含量区间**由论文的分位得分口径
  推算：以化合物在 250 款样本中的基准浓度为 100%，按「风格感官画像 × 化合物—感官敏感度」
  换算相对指数，再乘基准浓度；区间取基准的 ±20%～±30%，微量化合物下限置 0（未检出）。
- 论文明确给出的数值按原文使用并在页面上标注：表 12 的 Cohen's d、表 13 的三条风格轴、
  表 14 的 Tripel 位移清单、表 22 的缺陷阈值与样本数、表 27 的标记物核验。
- 感官画像为 0–6 相对分级；跨风格可比，绝对值不可外推到其他数据集。
- 迁移清单给出方向与量级，工艺放大前仍需以实测浓度复核。

论文出处与字段对应关系也可以站内点「数据口径」查看。

## 技术说明

- 无依赖：不用框架、不用 CDN、不发请求，全部 SVG 手绘，离线可用。
- 响应式：≥1180 / 960–1180 / <960（侧栏转顶栏）/ <640 四档；已验证 1440、1180、1024、768、390 宽度无横向溢出。
- 状态集中在 `app.js` 顶部的 `state`；六页各自一个地址，跳转走真实 URL，浏览器前进后退正常。
- 品鉴笔记由规则引擎生成（化合物 → 感官轴 → 句式三层），不使用大模型，结果可复现：
  同一组合与同一 seed 输出一致，「换一种写法」只切换句式模板。

## 视觉与交互规范

颜色、字号、动效都收在 `assets/css/style.css` 的 `:root` 里，改一处全站生效。

### 颜色与对比度

| 用途 | 变量 | 在深底 `#0e0c0a` 上的对比度 |
| --- | --- | --- |
| 正文 | `--ink` `#f4ecdd` | 16.6 : 1 |
| 次级正文 | `--ink-2` `#d9cdb9` | 12.4 : 1 |
| 说明文字 | `--muted` `#a2957f` | 6.6 : 1 |
| 小注与标签 | `--muted-2` `#8f8577` | 5.4 : 1（面板上 5.0 : 1） |
| 控件边框 | `--line-control` | 3.1 : 1 |

上一版的 `--muted-2` 是 `#7d7365`，在深底只有 4.19 : 1、面板上 3.76 : 1，低于正文所需的 4.5 : 1；
控件边框只有 1.9 : 1，低于非文本控件所需的 3 : 1。这两处都已调到达标。

### 字号阶梯

`h1 clamp(26–38)` / `h2 17` / `h3 13.5` / 正文 `14` / 导语 `14.5` / 小注 `11` / 等宽标签 `10.5`。

`h3` 原来用 `--ink-2`，比正文还暗，层级是倒的；现在改用 `--ink`，靠字号和字距区分层级。
首页主标题加了 `text-wrap: balance`，并让「226 个」之间不可断行，避免出现「226 / 个」这种拆法。

### 动效

只留三档，共用一条缓动 `--ease: cubic-bezier(.22,.8,.3,1)`：

- `--dur-1` `0.13s`：按下、表格行高亮
- `--dur-2` `0.22s`：悬停、颜色与边框
- `--dur-3` `0.4s`：页面进场

全站不再使用 `transition: all`（原来 5 处），改成显式列属性，
避免无意间给 `width`、`height` 这类会触发布局的属性加过渡。

### 交互状态

- **悬停**：卡片上浮 2px、边框转琥珀；按钮变亮或描边加深。
- **按下**：统一 `scale(0.97–0.994)`。上一版全站 `:active` 是 0 处，触摸屏上点完没有任何反馈。
- **聚焦**：`:focus-visible` 2px 琥珀描边。搜索框和下拉自己声明了 `outline: none`，
  特异性会压过全局规则，因此单独用更高特异性把描边补回来。
- **键盘**：风格卡原本是 `<article>`，鼠标能点、键盘进不去；已补 `role="button"` 与 `tabindex="0"`，
  Enter / Space 都能打开。

### 性能

动效只碰 `transform`、`opacity` 与颜色，不触发重排；图表和插画仍是内联 SVG，不增加请求。
`will-change` 只加在真正会动的元素上。

## 3D 发酵舱

化合物页工具栏的 **「进入 3D 实验室」** 会打开一个全屏 3D 场景：

1. **开屏加载**：三层旋转环、百分比、分段文案（建立坐标系 → 载入指标 → 校准光源 → 生成货架 → 注入化合物），约 2.2 秒，可点 SKIP 跳过；
2. **全场景实验室**：地面网格、后墙灯带、两只发酵罐、三层货架（24 罐原料）、中央酒瓶与 3D 小人；
3. **自由视角**：拖动空白处旋转（水平 360°、垂直有限位），滚轮缩放，松手有惯性；
4. **拖拽投料**：从货架拖一罐到瓶口，松手后化为光点落入瓶中，液面与颜色补间，小人举杯试饮，HUD 分数同步；也可以直接点一下罐子；
5. **退出**：点「退出 3D」或按 Esc，选择会同步回 2D 页面。

**技术选择**

- **Three.js r134 本地版**（`assets/vendor/three.min.js`，602 KB），不用 CDN：断网、`file://`、校园网都能开；只在 `lab.html` 加载，其余五页不付这份成本。
- **立体感不靠堆面数**：24 个罐子各 4 个网格、酒瓶用 `LatheGeometry`、小人由球/柱/环拼成，总计不到 200 个 draw call；像素比上限 1.8，只在覆盖层打开时渲染。
- **色调映射**用 ACES + 0.82 曝光，配合半球光 0.08 + 一盏主聚光，避免“塑料感”。
- **颜色只有一处真相**：3D 不复制化合物数据，所有名称、颜色、评分都通过 `window.AtlasLab`（`label / snapshot / toggle / setMode`）向 `app.js` 取。
- **降级**：没有 WebGL 或 Three.js 没加载时，覆盖层显示说明和「返回 2D」，2D 试饮台不受影响；`prefers-reduced-motion` 下跳过加载与待机动画。

**交互细节**

- 鼠标悬停罐子时显示名称与所属族，避免常驻标签糊满货架；
- 已经在瓶里的原料，罐底有一圈青色选中环；
- 拖拽时瓶口高亮，靠近才允许投放；
- 窄屏（< 720px）自动把镜头拉远、两位主角向中间收，手机也能同时看到瓶子和人。

## 中英文切换

右上角有 `中 / EN` 开关，选择记在 `localStorage`，切换时整页重渲染，品鉴笔记也会换成英文版本。

**文案表**：`tools/i18n_zh_en.tsv`，一行一条 `中文原文 <TAB> 英文`，共 700 条覆盖全站
（界面标签、表格列名、说明段落、55 个化合物的气味/口感/余味/机制描述、22 个风格一句话）。
改完重新生成即可生效：

```bash
python tools/build_i18n.py     # 输出 data/i18n-en.js
```

几点实现约定：

- **专名不重复翻译**：化合物、风格、感官轴、风味族的英文直接取 `data/flavor-data.js` 里的
  `en` 字段，文案表里只放句子和标签。
- **数字占位**：表里可写 `{n}`，运行时按原句数字顺序回填，所以「127 字 / 98 字」共用
  `{n} words` 一条；含数字的说明句同理。
- **不做逐词替换**：英文靠文本节点级整句匹配，匹配不到就保留中文，不会拼出半句英文。
  中英混排会漏空格的地方（`its<b>Key…`）在渲染后统一补空格。
- **品鉴笔记单独生成**：英文笔记由 `app.js` 里的 `buildNoteEn()` 用英文句式和词表重写，
  不是把中文逐句译过去，所以 `AROMA / PALATE / FINISH` 三段读起来是自然的英文；字数改为按词计。
- **自动去重**：中文标题旁本来就有的英文小注（如「糖化 Mashing」），在英文模式下自动隐藏，
  避免出现「Mash Mashing」。

## 首页开屏

打开 `index.html` 先是一段约三秒的开屏：巨型 `POUR` 被琥珀色液体从下往上灌满，
`226 / 55 / 22` 同时从 0 滚到位，然后整层向上掀起，页面从下方顶入。

- **文案只留一个词**：`POUR`。既是动作，也解释了画面里正在发生的事。
- **冲击力来自尺寸与对比**：字高 `clamp(104px, 25vw, 360px)`，
  奶油白 `#f4ecdd` 与琥珀 `#e9a94e` 在同一个字母内部形成分界，不靠额外装饰。
- **液体填充**用 `background-clip: text` 加一个可动画的 `--fill` 百分比（`@property`），
  液面处叠一条发光短线。不支持 `@property` 的浏览器停在奶油色文字，仍然可读。
- **时间轴**：0.1s 顶部细线展开 → 0.25s 字母上浮 → 0.6s 液面上升 1.45s →
  1.16s 数字滚动 → 2.9s 自动收场。光晕跟随鼠标，只在有指针的设备上启用。
- **随时可跳过**：点击、滚轮、触摸、任意按键都立即结束，右下角另有跳过按钮。
  收场后 `#intro` 从 DOM 移除，监听一并清掉。
- **收场是幕布上移 + 页面顶入**：两者同速，接缝处露出的始终是页面顶部，
  不会出现「透过缝隙看到页面中段」。页面位移交给 Web Animations API，避免和 CSS 抢 transform。
- **同会话只播一次**：`sessionStorage` 记 `atlas-intro-seen`，站内点「首页」回来不会重播。
  `?intro=1` 强制播放，`?intro=0` 关闭，方便演示与截图。
- **减少动态**：`prefers-reduced-motion` 下完全不播，直接进首页。
- **不挡键盘**：开屏期间 `.shell` 设 `inert`，Tab 不会跑进被遮挡的内容。

样式在 `assets/css/intro.css`，脚本在 `assets/js/intro.js`；只有首页加载这两个文件，
其余五页由 `build_pages.py` 条件注入。

## 化合物交互：3D 实验室与两种模式

页面 02 有两套说法，工具栏右侧切换，选择记在 `localStorage`（`atlas-mode`）：

| 模式 | 目录 | 标题 | 适合 |
|---|---|---|---|
| **小白模式**（默认） | 55 样日常原料：香蕉、黄油、煮玉米、篝火烟…，下面小字才是化合物名 | 调一杯自己的啤酒 | 第一次接触的人 |
| **专家模式** | 55 个化合物原名 | 把配方拆成化合物 | 看得懂感官轴与含量区间的人 |

两种模式共用同一套数据与同一个场景：切模式只换「怎么称呼」，不换「算什么」。
原料表在 `data/ingredients.js`，一个 id 对应一条 `{cn, en, emoji, note, noteEn}`；
没有对照项的化合物会自动回退到化合物原名。

### 场景：一间小实验室

`reactor.js` 画的是 360×260 的 SVG 舞台：

- **立体感**来自柱面高光、瓶口与底座的椭圆、台面投影，以及身体的径向渐变；
- **吊灯**在瓶子上方投下一束暖光，台面是一块有厚度的木板，小人在吧台后面；
- **视差**：鼠标在舞台上移动时，整块 SVG 按 ±5° / ±3.2° 轻微转头（`--rx-tx/ty` + rAF 节流，`prefers-reduced-motion` 下关闭）；
- **整页背景**是另一张固定定位的 SVG（`mountLab3d()`）：右上酒架、两只吊灯、墙缝与地面，只画在未放面板的区域，不抢正文。

### 入瓶 + 试饮

点左栏任一原料/化合物，会同时触发两段动画：

**① 入瓶**（`fly()` / `pour()`）

1. 从被点击的那一行飞出一滴（颜色取该化合物所属风味族的颜色）；
2. 飞到瓶口后溅起一圈涟漪（`splash()`）；
3. 液面上升、液体颜色补间，同时冒出一串气泡（`bubbles()`），瓶身光晕亮一下。

**② 试饮**（`sip()` / `switchFace()`）

评分出来后，小人把杯子抬到嘴边、头后仰 7°、停一下再放下，杯口留一圈奶泡。
表情按 0–100 的口味评分切五档：难以下咽（X 眼、波浪嘴、吐舌、汗滴）/ 不太妙 / 中规中矩 / 不错 / 很好喝。
换表情时旧表情 130ms 淡出、新表情 280ms 带回弹淡入；极好会点头，极差会摇头并让脸泛绿。

**口味评分怎么来的**

`app.js` 的 `tasteScore()` 把化合物的感官权重按愉悦度加权：酯香 +1.0、麦芽 +0.82、花香 +0.78、
酒花 +0.5、苦味 +0.12、酚味 −0.12、硫味 −1.0、氧化 −1.0，映射到 50 ± 42 的区间。
双乙酰、DMS、反-2-壬烯醛这类「感官描述听起来还行、实际是缺陷」的化合物，用 `TASTE_FIX` 单独钉死。

**为什么切换时不闪跳**

面板每次选择都会整块重渲染，DOM 是新的。`reactor.js` 用模块级的 `prev` 记住上一帧的液位、颜色、表情，
`attach()` 先把新节点摆回旧状态（同一帧内、绘制之前），下一帧再补间到新状态。

**为什么不影响布局**

舞台是固定 360×260 的 SVG（桌面 316px 宽，≤640px 时 280px 并上下堆叠），
动画只改 SVG 内部的 `transform` / `opacity`。实测切换过程中面板高度恒为 309px。
飞出的那一滴是 `position: fixed` 的临时节点，动画结束即移除（另有 900ms 兜底清理）。

**调参**

| 想改什么 | 改哪里 |
|---|---|
| 液体补间速度 / 落点后等待 | `reactor.js` 里 `tweenLiquid(...)` 的 `dur`、`var gap` |
| 飞行时长与弧线 | `fly()` 的 `dur` 与中间关键帧的 `-46px` 抬升 |
| 表情切换速度 | `switchFace()` 里的 130 / 280 ms |
| 五档阈值与文案 | `app.js` 的 `tasteEx()`、`TASTE_WORD`，文案在 `tools/i18n_zh_en.tsv` |
